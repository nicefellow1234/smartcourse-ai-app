About SmartCourse

SmartCourse combines classical information retrieval with modern semantic search to deliver tailored course recommendations.

Technology Stack

  • Flask REST API with SQLite persistence
  • TF-IDF vectorization and cosine similarity via scikit-learn
  • Sentence-Transformers (all-MiniLM-L6-v2) embeddings for semantic matching
  • Bootstrap 5 interactive frontend

Dataset Preparation

The project expects the Course Recommendation System dataset (8,500+ courses). Data pipelines clean, deduplicate, normalize, and enrich metadata prior to model training.

Team

Developed under the supervision of Muhammad Bilal (bilal.saleem@vu.edu.pk).
